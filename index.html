Adroit — AdMob for Android, in a few lines of Kotlin

My role: Creator and sole maintainer. The source repository is private; the artifacts are public on Maven Central (io.github.thesobiaakbar:adroit-*) under Apache 2.0.

A library that wraps the Google Mobile Ads Next-Gen SDK and Google's consent SDK (UMP) behind one small API for both XML and Jetpack Compose apps. Apps list their ads in one Kotlin file and can tune every ad from Firebase without a new release.

Key features

  • Every AdMob format: banner, native, interstitial, rewarded, rewarded interstitial and app open
  • Consent (GDPR, US states) handled before any ad request; splash flow with a timeout so it never gets stuck
  • Per-ad remote control from Firebase Remote Config: unit IDs, formats, counters, timers, frequency
  • Lifecycle-safe banners and native ads, leak-checked with LeakCanary; rewards granted exactly once
  • No Google types in the public API, enforced with Kotlin explicit API mode and API dump checks
  • Ten modules: core, views, compose, firebase, testing, plus matching in-app billing modules

CI/CD with GitHub Actions

  • CI on every push and pull request: build, tests, lint, docs check and a script that blocks forbidden code patterns
  • Instrumentation: nightly emulator test matrix on API 24 and 36, including an R8-minified build
  • Release: signed bundle to the Maven Central Portal, GitHub Packages and a GitHub release
  • Actions pinned to commit SHAs, Dependabot updates and a pull request template

Tech

  • Kotlin
  • Jetpack Compose
  • XML Views
  • Gradle build-logic
  • GitHub Actions
  • Robolectric
  • Firebase

Photo Recovery — Kotlin & Compose rebuild

My role: Sole developer (private repository) — architecture, build setup, features, tests and CI.

A rebuild of an existing React Native app in Kotlin and Jetpack Compose. It scans device storage for images, videos, audio and documents and copies recoverable files to a restored folder — entirely on the device, working in airplane mode.

Key features

  • Scans for images, videos, audio and documents, plus a deep scan
  • Originals never modified; a file counts as recovered only after its copy is verified
  • No file, name or path ever leaves the device
  • 16 languages including right-to-left Arabic and Urdu
  • Accessibility audit tests per screen: English, Arabic, 200% text, 320dp and tablet widths

Architecture & delivery

  • Modules: :app, :core:*, :recovery:domain (pure Kotlin), :recovery:engine and six :feature:* modules
  • Clean Architecture with MVI; features never depend on each other or on the engine
  • Gradle convention plugins in build-logic; baseline profile module
  • GitHub Actions: build, unit tests and detekt on CI, plus an end-to-end workflow on an Android emulator
